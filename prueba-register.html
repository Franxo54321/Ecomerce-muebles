Solución al error 404

El error 404 significa que el endpoint /api/register no existe en tu servidor.

Para solucionarlo, agrega este código a tu servidor:

// Ruta de registro en server.js o routes/auth.js app.post('/api/register', async (req, res) => { try { const { name, email, password } = req.body; // Validaciones básicas if (!name || !email || !password) { return res.status(400).json({ error: 'Todos los campos son requeridos' }); } if (password.length < 6) { return res.status(400).json({ error: 'La contraseña debe tener al menos 6 caracteres' }); } // Aquí debes agregar la lógica para: // 1. Verificar si el usuario ya existe // 2. Hash de la contraseña (usando bcrypt) // 3. Guardar el usuario en la base de datos // Respuesta de éxito res.status(201).json({ message: 'Usuario registrado exitosamente', user: { id: '123', // ID generado por la base de datos name: name, email: email }, token: 'jwt-token-generado' // Debes generar un JWT token }); } catch (error) { console.error('Error en registro:', error); res.status(500).json({ error: 'Error interno del servidor' }); } });

O alternativamente, usa el endpoint correcto:

// Cambia la URL en tu frontend de: const API_BASE = 'http://localhost:3000/api'; // a: const API_BASE = 'http://localhost:3000/api/auth'; // Y asegúrate de tener la ruta /api/auth/register en tu servidor
